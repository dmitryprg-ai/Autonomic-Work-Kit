# Demo-readiness A1–A7

Таблица снимается **фактическим прогоном**, а не по памяти и не по
чужому отчёту. Ячейка, которую не прогоняли, помечается как
непроверенная — это честный статус, а не провал.

| ось | что проверяет | типовая команда |
|---|---|---|
| **A1** install | зависимости ставятся с нуля | менеджер пакетов проекта |
| **A2** build | сборка проходит | команда сборки |
| **A3** typecheck | типы/статический анализ сходятся | команда проверки типов |
| **A4** test | набор тестов зелёный | команда тестов |
| **A5** lint | линтер чист | команда линта |
| **A6** local run | артефакт запускается локально и делает заявленное: сервис отвечает, CLI выполняет команду, библиотека импортируется и отрабатывает пример | запуск + наблюдаемый отклик |
| **A7** deploy | путь до среды развёртывания рабочий, версия наблюдаема снаружи | скрипт деплоя + проверка версии |

## Статусы

- 🟢 — прогнано сейчас, зелено, вывод приложен;
- 🟡 — прогнано, есть известная проблема с описанием и владельцем;
- 🔴 — падает или не прогонялось при заявленной готовности;
- `н/п` — ось **не применима к этому проекту**, с обязательной строкой
  почему.

## Про `н/п`

Оси описывают типовой проект, а не все проекты. Библиотека без сборки,
скрипт без типизации, репозиторий без тестового харнеса на старте,
CLI без «поднимается и отвечает», проект без среды развёртывания —
это нормальные проекты, а не сломанные.

`н/п` ставится только с обоснованием в той же ячейке: «сборки нет —
интерпретируемый язык, артефакт = исходники». Обоснования нет — статус
не `н/п`, а 🔴: разница между «не нужно» и «не сделали» и есть предмет
этой таблицы.

Отдельный случай — **A4 test при отсутствии харнеса**. Это `н/п` только
если проверять действительно нечем; если проверки возможны, но не
заведены, честный статус 🔴, и заведение харнеса становится первой
задачей: без него красная фаза цикла (протокол §4) вырождается.

## Правило приоритета

**Любой 🔴 на применимых осях A1–A6 становится задачей с классом `chore`
и `Метки: Alarm` в начало плана.** Без работающего локального запуска
остальной план бессмысленен: нечем проверять DoD. Оси со статусом `н/п`
в этом правиле не участвуют.

A7 может быть 🟡/🔴 дольше остальных — деплой не блокирует локальную
работу, но блокирует runtime evidence на реальной среде.

## Правило источника

Каждая ячейка несёт пометку, **кто и когда её получил**:
`прогнано мной сейчас` / `из отчёта ‹файл›, не верифицировано`.
Смешивать эти два состояния — тот самый случай «реализовано ≠ работает».
