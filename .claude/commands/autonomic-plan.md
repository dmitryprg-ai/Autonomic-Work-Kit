Собери план автономного исполнения строго по скиллу `.claude/skills/plan-builder/SKILL.md`.

Исходные данные: $ARGUMENTS

Пройди все шесть шагов скилла по порядку, ни один не пропуская:

1. Восстанови outcome верхнего уровня через `@outcome-designer`. Расхождение
   с формулировкой владельца — в блок `Gap`, не разрешай молча.
2. Legacy-инвентаризация ДО проектирования: параллельные и брошенные
   реализации. Живая параллель — первой задачей с `Метки: Alarm`.
3. Сними baseline A1–A7 фактическим прогоном. Не можешь прогнать — так
   и напиши, и поставь снятие настоящего baseline первой задачей. Оси,
   неприменимые к этому проекту, помечай `н/п` с причиной.
4. Построй иерархию Big→Medium→Small назад от outcome по критической цепи.
   Звенья цепи называй по `T-ID`. На цепи — только `outcome`.
5. Создай `PLAN.md`, `STATE.md`, `CLAUDE.md` по шаблонам из `templates/`.
6. Прогони `node scripts/plan-lint.mjs PLAN.md` и приложи вывод.

**Режим планирования: продуктовый код не пиши.** Красный линт = план не сдан.
Недостающие данные не выдумывай — выноси в открытые вопросы владельцу.

В конце дай сводку: outcome одной строкой, узкое место, число задач
по классам, состояние baseline, открытые вопросы.
