description: Запустить автономный цикл по PLAN.md — исполнять задачи до условия остановки
---
Работай по протоколу `.claude/rules/loop-protocol.md`. Прочитай его целиком
перед первой итерацией, а не по ходу.

Исполняй `PLAN.md` задача за задачей, **по одной Small за раз**, пока
не сработает одно из пяти условий остановки: `DONE`, `WAITING-OWNER`,
`FIVE-FAILS`, `PLAN-DRIFT`, `SCOPE-BREACH`. Других причин остановиться нет:
«кажется, достаточно» и «остальное мелочи» условиями не являются.

Каждую итерацию проходи полный цикл:
SELECT → ANNOUNCE → RED → EXECUTE → CHECK → VERIFY → [SLICE-AUDIT] → CLOSE.

Держи инварианты §0:
- одна задача в работе;
- `✅` без runtime evidence запрещён;
- найденное по дороге — в `FOLLOW-UPS`, не в текущий дифф;
- параллельную реализацию не создавать;
- числа только с замером;
- вердикт своей работе не ставить: после каждой задачи вызывай `@verifier`
  и записывай его вердикт дословно.

При закрытии последней Small внутри Medium или Big вызывай `@adversary`
на весь срез.

Когда цикл остановится — назови код остановки, что именно требуется
от владельца и чем это разблокируется.
